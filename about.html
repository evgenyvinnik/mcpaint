About MCPaint:
MS Paint online.

MCPaint is a free online drawing app inspired by classic Microsoft Paint. Sketch an idea, make pixel art, or edit a picture right in your browser. No download. No sign-up. Just open it and draw.

The classic Paint toolbox, in your browser

If you remember drawing with MS Paint, the tools will feel familiar. MCPaint brings the Windows 98 style of painting to the web, with 16 tools for drawing and editing. Use it for a quick doodle, a simple diagram, an image annotation, or a little digital art.

Draw and paint
Sketch with the Pencil, paint with the Brush, add texture with the Airbrush, and clean up with the Eraser. Fill with Color and Pick Color help you work with a palette.
Build shapes and add words
Use the Line, Curve, Rectangle, Polygon, Ellipse, and Rounded Rectangle tools for outlines and filled shapes. Add a caption or label with the Text tool.
Select and refine
Move parts of a picture with Rectangular Select or Free-Form Select. Use the Magnifier to work on details, then undo or redo changes as you experiment.

A simple pixel art editor online

MCPaint is useful for small sprites, icons, and other drawings where each pixel matters. Start with a small canvas, choose the Pencil for single-pixel marks, and zoom in to place colors precisely. Turn on the grid from View > Zoom > Show Grid at 400% zoom or higher to see the pixel boundaries.

Try a small palette and use Fill with Color for enclosed areas. Zoom back out to check the picture at its actual size. Save pixel art as PNG to keep its crisp edges and colors.

How to draw or edit an image online

  1. Open the canvas. Launch MCPaint to start drawing, or choose File > Open to work on an existing image.
  2. Pick a tool and a color. Try the Pencil or Brush for freehand drawing, or use shapes and Text to mark up a picture.
  3. Make it yours. Select and move an area, adjust the canvas through Image > Attributes, or use undo to try another direction.
  4. Save a copy. Choose File > Save As, give your picture a name, and select an image format such as PNG, JPEG, or BMP.

For help with a particular tool, open Help > Help Topics inside the app.

Questions about MCPaint

Is MCPaint free to use?

Yes. You can draw, edit images, and save your work without paying or creating an account. The source code is also available under the MIT License.

Can I use MCPaint on a Mac, Chromebook, or Linux computer?

MCPaint runs in a modern web browser, so you do not need Windows or an installed copy of Paint. You can open the app on macOS, ChromeOS, Linux, or Windows. A mouse is helpful for precise drawing.

Is this the official Microsoft Paint?

No. MCPaint is an independent, open-source project inspired by classic MS Paint and based on JS Paint. It is not affiliated with or endorsed by Microsoft.

Does MCPaint save my drawing?

The app keeps a local backup of your work in your browser. Browser data can be cleared, so use File > Save As to keep a separate image file on your device. A browser backup does not sync your drawing between devices.

Does MCPaint have an AI drawing assistant?

Yes. Open View > AI Assistant to describe what you want to draw in words. The assistant can use drawing commands on the canvas. This feature requires an internet connection and an available AI service.
